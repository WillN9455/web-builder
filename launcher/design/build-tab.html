Build & deploy rules

writes to code-builder/build-rules.md

Build lifecycle (5 steps). Every story moves through these states on the Sprint board:

  • Picked up → Code Agent pulls the story into their worktree.
  • Building → Code Agent writes FE files, BFF routes, BE handlers, and a unit test per changed module.
  • Self-review → Code Agent runs the linter, formatter, and the test suite locally; fixes the failures it can.
  • For review → PR is open; Reviewer Agent reads the diff against the linked requirement and the design.
  • Ready for QA → merged to main; QA Agent picks it up and runs the Playwright suite.

CI gates. A PR cannot be marked Ready for review unless pnpm lint, pnpm test, and pnpm typecheck all pass on the PR branch.

Deploy targets. Merges to main auto-deploy the FE to Vercel (preview URL per PR) and the BFF + BE to Fly.io (qa-env for QA passes, prod for explicit releases only).

Branch policy. Story branches are build/{TM-XX}-{slug}; hotfix branches are hotfix/{slug}. No direct pushes to main.

Per-agent coding guidelines

one per Code Agent + Reviewer · writes to code-builder/agents/{name}.md
C1
Code Agent 1 — FE focus Active now · Building TM-23 (Photo upload) · ~2h elapsed

Scope. Owns React pages, components, hooks, and styles under src/.

  • One component per file. File name matches the default export.
  • Props are typed with interface, not type.
  • Every page exports a route-level loader; no data fetching in useEffect.
  • All interactive elements have a visible focus ring (4px navy).
  • a11y: every <img> has alt, every form input has a <label>.
C2
Code Agent 2 — BFF focus Idle · last shipped TM-18 1h ago

Scope. Owns the Express BFF under server/bff/ and the route mapping.

  • Routes are registered via app.use('/api/...', router); one router per resource.
  • Each route is a thin shim that calls into the BE handler — no business logic in the BFF.
  • All errors are wrapped in { ok: false, error: { code, message } }.
  • Auth: requireAuth middleware on every route except /auth/* and /health.
C3
Code Agent 3 — BE focus Idle · last shipped TM-19 38m ago

Scope. Owns Node 22 route handlers under server/be/ and the SQLite schema.

  • Handlers are pure functions: (db, req) => Result. No I/O outside the db argument.
  • All writes are atomic (single db.transaction(...) call).
  • Migrations live in server/be/migrations/ as NNN-{name}.sql; never edit a shipped migration.
  • Use RETURNING * on every insert/update so the caller doesn't have to re-fetch.
RV
Reviewer Agent Active now · Reviewing PR #214 (TM-19) · ~22m elapsed

Scope. Reviews PRs against the linked requirement and the design.

  • Read the linked requirement first; the PR exists to satisfy it.
  • Check a11y on every new page or modal (focus order, ARIA labels, contrast).
  • Check for IDOR: every :id route must authorize against the current user.
  • Approve only if all checks pass; otherwise leave specific, actionable nits.
