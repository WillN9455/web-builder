# Design stage skills

Skill files the Design Agent loads on demand (per CLAUDE.md § Skill Invocation
Rules). Each file is one skill: a self-contained checklist/rulebook the agent
consults when the task touches that concern.

- `accessibility-guidelines.md` — a11y rules (WCAG targets, contrast, focus, semantics)
- `ui-best-practices.md` — UI completeness checklist

Bodies are the migrated repo-root rulebooks; this folder is their canonical home.
