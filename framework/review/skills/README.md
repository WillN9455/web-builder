# Review stage skills

Review deliberately owns **no skill bodies**. The Reviewer Agent audits work
produced by other stages, so its skill set is the *shared* rules those stages
were held to — it reads them via `../../shared/skills/` rather than keeping
copies that could drift from the enforced version.

If a review-specific skill emerges (e.g. a review-checklist skill no other
stage consumes), it lands here as a single-consumer skill.
