# Shared — cross-stage skills

Skills that apply to more than one stage live here instead of being copied
into every stage folder. Stages declare them in `manifest.json` as inputs.

**Debate flag (v1):** Solution Architect may argue the old flat `skills/`
pool was simpler and stage folders should just point at it. v1 keeps a small
`shared/` (one file) rather than the whole pool — see `shared/skills/README.md`.
